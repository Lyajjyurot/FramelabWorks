# 帧动画工坊 (Sprite Frame Studio)

本地离线的视频转透明帧动画工具。单 HTML 文件，无需安装，打开即用。

## 功能

- **视频时间裁剪** — 精准设定起止时间（秒 + 毫秒）
- **自定义间隔抽帧** — 支持每 N 帧抽取 1 帧，可选 ffmpeg.wasm 精确模式
- **帧手动筛选** — 缩略图预览，全选/反选/逐帧选择
- **画布框式裁剪** — 拖拽绘制选框，八把手缩放，九宫格辅助线
- **批量抠图** — 色差抠图（YCbCr 色度差算法）+ Alpha 通道提取，支持吸管取色、橡皮擦、抗锯齿羽化、去白边
- **导出** — 透明 GIF 动画 / ZIP（PSD 分层 + 每帧透明 PNG）

## 特性

- **100% 本地离线** — 所有处理在浏览器完成，视频不上传
- **单文件** — 一个 HTML 文件即可运行，无需构建
- **支持多视频** — 同时导入最多 10 个视频，独立处理

## 使用方法

直接在浏览器中打开 `sprite-frame-studio.html` 即可。

推荐使用 Chrome / Edge 等现代浏览器。

## 流程

```
导入视频 → 裁时间 → 抽帧 → 选帧 → 框裁 → 抠图 → 导出
```

## 技术栈

- 纯原生 HTML / CSS / JavaScript，无框架依赖
- 可选：ffmpeg.wasm（联网时按需加载，用于精确抽帧）
